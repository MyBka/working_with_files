# Лабораторная работа 1

Утилита WordCount

## Задача.

Реализовать [утилиту](https://ru.wikipedia.org/wiki/%D0%A3%D1%82%D0%B8%D0%BB%D0%B8%D1%82%D0%B0) WordCount, подсчитывающую количество строк, слов, латинских букв, цифр и байт для указанного файла и выводящую эту информацию в поток вывода.
Программа должна поддерживать следующие опции:

| Короткий аргумент | Длинный аргумент | Описание |
|-------------------|------------------|----------|
| `-l` | `--lines` | Вывод только количества строк |
| `-c` | `--bytes` | Вывод размера файла в байтах |
| `-w` | `--words` | Вывод количества слов |
| `-a` | `--alnum` | Вывод количества латинских букв и цифр |


Название файла и опции передаются через аргументы командной строки в следующем формате:

```shell
WordCount.exe [OPTION]... [FILE]...
```

### Формат вывода

Для каждого файла выводится одна строка:

```text
<lines> <words> <alnum> <bytes> <filename>
```

Колонки всегда идут в этом порядке, независимо от порядка опций в аргументах. Выводятся только запрошенные колонки. По умолчанию (если опции не заданы) выводятся:

```text
<lines> <words> <bytes> <filename>
```

Числа и имя файла разделяются ровно одним пробелом. Имя файла выводится так, как оно было указано в аргументах командной строки.
Для каждого файла результат выводится на отдельной строке в порядке передачи файлов в аргументах командной строки. Общее количество по всем файлам выводить не нужно.

### Правила подсчёта

- Строка заканчивается символом перевода строки `\n`. Последняя непустая последовательность символов без завершающего `\n` также считается строкой. Пустой файл содержит 0 строк.
- Слово является непустой последовательностью непробельных символов. Пробельными считаются: пробел (`' '`), горизонтальная табуляция (`\t`), перевод строки (`\n`), возврат каретки (`\r`), вертикальная табуляция (`\v`) и перевод страницы (`\f`).
- Опция `--alnum` подсчитывает латинские буквы (`A-Z`, `a-z`) и десятичные цифры (`0-9`). Все остальные байты не учитываются.

### Примеры запуска программы:

```shell
./WordCount filename1
./WordCount filename1 filename2
./WordCount --words --lines filename1
./WordCount --alnum filename1
./WordCount -l -c filename1
./WordCount -lawc filename1 filename2
./WordCount filename1 filename2 -lw --bytes
```

## Примечание

- Для реализации утилиты потребуется воспользоваться стандартной библиотекой ввода/вывода ([описание](https://en.cppreference.com/w/cpp/io/basic_ifstream)).
- Пример того, как можно организовать парсинг аргументов командной строки, можно посмотреть [здесь](http://www.cplusplus.com/articles/DEN36Up4/).
- Учтите, что размер входного файла не ограничен и может превышать объем доступной оперативной памяти.
- Имена файлов могут начинаться с `-` и `--`, однако в рамках данной лабораторной работы мы считаем, что утилита не обязана такие файлы поддерживать. Подумайте, как можно реализовать поддержку файлов, начинающихся с `-` и `--`, посмотрите, как это делают другие утилиты.
